# zomato-mcp

hi zomato team! 👋

i'm planning to use this with an OpenClaw agent running locally to automate parts of my ordering flow — reorders, finding stuff i actually like, that kind of thing.

beyond that, i want to tinker and see what else becomes possible once Zomato is wrapped as an MCP server. some directions i'm curious about:

- **smarter reorders** — "order what i had last tuesday but make it healthier"
- **group ordering** — agent coordinates picks across a few people and places one order
- **dietary-aware browsing** — filter menus by what i actually eat, not just cuisine tags
- **spend tracking** — let the agent summarize where my food budget is going each month
- **discovery** — "find me something new but in the same vibe as my last 5 orders"

no github link to share yet — this is purely local exploration for now. if there's an official path for this kind of agent integration, would love to hear about it.
